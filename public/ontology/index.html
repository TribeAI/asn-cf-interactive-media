Content Ontology — Roles → Jobs to be Done → Topics

A content-derived ontology over 20 MS Learn modules, linking three layers: derived roles (personas) → the jobs to be done they pursue → the topics those jobs draw on. Topics come from the v3 topic extractor and are joined to jobs by semantic similarity; near-duplicate topics are merged into shared hubs. Click any node to trace its full path through the ontology.
Scope: "Roles" here are content-derived persona clusters, not Microsoft's frozen ASN role taxonomy. Topics is the layer Tribe owns; roles and Viva Skills are owned, frozen taxonomies shown only as context.
