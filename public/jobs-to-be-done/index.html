Jobs to be Done

The goals a learner uses each MS Learn module to accomplish — the action/outcome axis alongside topics — extracted per-module from body text by a local Qwen3.6-35B model (zero-shot). Personas are a lightweight derived grouping signal, not a role taxonomy. Click a persona to light up the jobs it groups — or click a job to see which personas draw on it.
Scope: "Jobs to be done" is Microsoft's preferred framing (moving away from rigid roles). Microsoft's roles (ASN) and skills (Viva Skills) are owned, frozen taxonomies and out of scope here — this view deliberately does not reproduce them. Personas below are an informal clustering aid only.
